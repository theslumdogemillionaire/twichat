Drop the published builds here if you set neither `TWICHAT_RELEASE_BASE` nor a per-platform URL.
The names carry the version, so they change with every release:

- `Twichat-<version>-mac.dmg`
- `Twichat-<version>-windows.exe`
- `Twichat-<version>-linux-x86_64.AppImage`, `Twichat-<version>-linux-arm64.AppImage`
- `Twichat-<version>-linux-amd64.deb`, `Twichat-<version>-linux-arm64.deb`
- `Twichat-<version>-linux-x86_64.rpm`, `Twichat-<version>-linux-aarch64.rpm`
